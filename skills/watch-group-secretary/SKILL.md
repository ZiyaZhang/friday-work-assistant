# 盯群秘书

只在私聊里成立。盯群用的是**发起人自己的身份**，所以它能看的就是发起人能看的；读到的内容只回到这个私聊，群里仍然只用机器人身份说话。没有个人授权时说清楚这件事要先授权，并让网关把授权卡发过去（卡上有按钮）；不代劳、不改用机器人身份去读别的群，也不要让他去敲命令。

## 登记

先 `feishu_list_chats` 或 `friday_visible_groups` 定位群。按名字匹配到多个就先确认是哪个，不任选第一条；匹配不到不要猜近似名。

`friday_watch_add` 登记，主题写用户的原话范围（"只报和上线相关的"、"有人 @我 或需要我拍板"），不扩写成"所有重要信息"。默认 `when_nonempty`：没有命中关注重点就静默，不发"本次无更新"。用户明确要求每次都汇报时保存 `delivery_policy="every_run"`，只写进 prompt 不算数。

汇报方式按用户交代的分寸走，两种都要能做：直接发到这个私聊；或归档——要读的用 `feishu_create_document`，要筛选排序、持续追加的用 `feishu_create_table`。用户没说就先发私聊并问一句要不要归档。

## 每一轮

按上次游标读增量 `feishu_read_chat_history`，命中的话题用 `feishu_read_thread` 展开再下判断。分页截断、话题没展开、卡片解析不了都是**覆盖缺口**，要在汇报里写出来；读取失败不能写成"这段时间没有事项"。

汇报保持一屏：3–6 条真实变化，每条带发言人、时间和可点链接，同一件事合并成一条。聊得热闹不等于重要，按关注重点判断，不按消息条数。

## 点名你的永远报——这条优先于关注重点

关注重点是**过滤器**，但有一个例外：**群里点名他的，无论符不符合关注重点，都要报。**

他说"只报和上线相关的"，结果有人在群里 @ 他问别的事——那条仍然要报。否则"帮我盯着"这个承诺就是假的，而漏掉一条点名他的消息，比多报一条无关的代价大得多。

点名包括三种，都算：

- **@ 了他**且带请求或问句（"@张三 这个你看一下"）；纯客套（"@张三 谢了"）不算
- **没 @ 但明确分给他的**（"这个让知行看"、issue 指派给他）
- **在等他拍板**（"等张三定了再说"）

这三种同时**记成待办**（判断标准照 `todo-extraction`，owner 写他），并在汇报里单独列在最前面，别混在普通变化里。推断出来的只能是候选，不写成承诺。

## 授权、暂停与停止

授权失效只暂停**这一组**，其他关注照常。续权后从上次游标接着读，不补发失效期间的历史，也不声称"消息不会丢"。用户手动暂停的不因续权自动恢复。

"这个群别跟了"用 `friday_routine_control` 的 `delete`，并在回执里说清：哪些定时任务被移除、已归档的表格或文档还在不在、当前还在关注哪些群。暂停和删除是两件事，不能互相替代。

## 边界

眼睛可以看别群，嘴和手留在本空间：盯群读到的内容不能带进任何群聊回复，也不写成本空间之外的长期记忆。发起人撤权后，已派生的摘要和待办正文一并停用，只保留不含正文的壳与状态。
