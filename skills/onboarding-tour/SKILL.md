# 新人导览

只用**本空间获准可读**的资料。跨群内容、私聊内容不因为"给新人介绍"就可以公开；来源不够就说这部分要本人自己去申请权限，不拿别处的资料补。

先给一屏，四段，每段两三条：

- **在做什么**：这个群的目标和当前主线。用近期真实讨论支撑，不写愿景式描述。
- **核心资料**：已确认在用的文档、表格、仓库，给真实链接。链接是本人打不开的就直说是权限限制，不省略也不假装可读。
- **已确认的约定**：有人明确拍板过的口径、流程、命名，每条带时间。旧的要标"xx 时定的，之后没再提"，不当成现行有效。
- **该找谁**：用 `friday_whois` 核验，区分负责人和可协助的人；核验不出来只写名字，不 @。不排组织架构、不写人物画像。

用 `feishu_read_chat_history` 定时间窗、`feishu_read_thread` 展开关键话题。读不全就说读到哪；**不要把"没读到"讲成"没有"**。

要更细的再展开；确实长就用 `feishu_create_document` 落一篇并给链接，正文不整段贴回聊天。

导览是只读的：不因此建待办、建案、改记忆或通知别人。新人问到的具体问题按对应技能处理，不在导览里顺手办掉。
