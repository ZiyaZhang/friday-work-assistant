# 空间、记忆与简报：本批工程契约

保留单进程 SQLite、DSH 执行和 GitHub 正式状态源。本批在已有对象上修语义与取消窗口，不重建业务平台。

## 空间生命周期

`SpaceLifecycle.stop()` 在同库事务内保留群绑定并停用空间，暂停生效职责、取消未完成 occurrence、归档该群全部会话、取消排队和运行任务、失效消息别名。提交后再中止 ACP。关闭外部运行失败不能重新开放接入或发布。

普通消息和重新加群都不恢复空间。负责人通过 `/space resume` 显式恢复，网关读取当前群成员并在等待后重验负责人。原空间、资料、配置保留；旧任务不重跑，职责保留读取游标但须逐项重新启用，原本手动关闭的职责保持原原因。

恢复或重开使用新执行会话键，聊天锚点重新指向它；旧键不复用。ACP 创建/恢复、上下文读取、最终发送、Wiki 分组和轮末整理中的等待均检查会话是否仍有效。已发出的 HTTP 不能撤销：迟到成功只保留投递收据，不把任务改回完成、不再写 QA/别名，也不重发或撤回。

当前 `/space rebind` 不执行部分迁移。它明确说明尚未换绑，保留两边数据与绑定；完整迁移仍需目标群身份校验、明确可移内容及职责/文件/文档目标的一致迁移，不能把当前入口关闭算成功能完成。

## 记忆与偏好

自动 QA、MCP 记忆和自动整理先记候选；确认凭据来自实际人的确认消息。旧记录不能由 source.by 推造确认，迁移保留原表快照，详见 确认记忆迁移。周报按实际确认时间取新确认项。

个人默认仅沿用回答长度、状态反馈。群注记、主动规则、模型和仓库配置不继承；旧 user_defaults 读取时同样过滤。已存在空间里无法区分手工与继承的旧注记不擅自删除。

## 每日简报

沿用 group-digest 与 routine-management；常驻提示不加专门分支。简报使用现有已授权群、GitHub、待办和本人日历工具：短开场、约 3–6 条重要变化、1–2 句今日优先事项，条目附实际链接。同事项讨论和 PR 合并呈现，不能凭抓取时间声称未读，不能编造邮箱接入。

职责明确规定的格式与无变化约定优先；普通 watch 没变化静默，约定每天发送的简报可以给简短空结果。技能与默认提示已连接，实际模型是否稳定满足长度、选材和来源仍待实机验证。
