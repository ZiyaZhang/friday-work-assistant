# Context Builder 第一段替换（A1）

2026-09-20。本片对应 [目标架构第⑤层](target-architecture.md)，只迁移普通请求及补问接续的本地上下文组装。尚未部署。

## 实现边界

TurnContextBuilder 接收宿主已核验的 task、空间、发言人、配置、读取范围，以及已取得的话题历史和附件说明。它同步读取当前记忆、真实 Task 补充链、问题/答复及案件状态，返回 prompt、ContextReceipt 和实际查询过的记忆作用域。

Orchestrator 保留外部读取、当前 Run 核验、来源累计、回执存放和执行生命周期；不再自己把案件/答复映射成 prompt。prompt.ts 继续只负责表达。没有新增数据库表、权限旁路、通用插件注册表或缓存。

readScopes 放在附件/群名/作者等异步读取完成且 assertCurrent 通过之后，避免在等待期间授权变化后仍用旧范围读取新记忆。已有 delivery-sources 继续保守累计查询层，包含空层；不为了让正常场景通过而删除旧来源限制。

## 验证范围

新增 7 个回归场景：

1. 同一工作继续组装时读取已确认的更正；候选事实保留未确认标识。
2. 连续补充只带真实关联原文与状态，不混入同会话的无关请求。
3. 问题已拒绝、案件关联 Issue 后重新读取最新状态，不改写原文。
4. 保留历史分页/卡片缺口、附件说明与回执信息。
5. 只读取宿主提供的当前记忆范围，不引入其他空间。
6. 当前问题与空间/工作不匹配时不注入案件内容。
7. 真实 Orchestrator + ACP 夹具：附件读取期间撤销联盟关系，新组装不读撤权后加入的联盟记忆；既有累计来源仍保留，发布不得绕过原门禁。

第 7 项初版测试错误地期待累计来源消失，修正为保留来源并拒绝投递；没有为了通过测试改弱生产权限。

本地验证：类型检查、构建、相关 6 文件 202/202、全量 74 文件 1398/1398 通过。独立审查无新增阻断，并单独执行新增 7/7 回归。全量包含本工作树已有的 PR 追加提交改动，不是 1398 条新增上下文测试。


## 尚未完成

- 职责、主动判断与学习仍未全部调用同一个 Builder。
- ContextReceipt 仍只在内存，持久 Manifest 依赖下一阶段的持久 Run。
- 当前 Builder 的输入是宿主核验结果，本模块不是权限服务。
- 本轮 prompt 不再注入旧记忆，不等于旧 ACP 会话已经忘记历史；会话失效与重建属于 C 阶段。
- 来源仍按 Session 累积，尚未细化到每个派生产物。
- 普通话题工作目录、空间技能绑定及 OS 隔离没有因本次抽取而完成。

本片是模块边界替换，不能宣称已完成八层重构或全部协作功能验收。
